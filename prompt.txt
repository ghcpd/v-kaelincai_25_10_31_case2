Role
You are a software engineer responsible for implementing and testing the capabilities of AI models on the Regression subtype within the Bug-related category.
Your task is to provide two separate, complete Python projects:
________________________________________
1.	Project A – Pre-Optimization (Faulty Implementation)
A project that contains the original, faulty, or inefficient implementation that demonstrates a regression issue — for example, previously working functionality now fails or behaves incorrectly after a change.
2.	Project B – Post-Optimization (Improved Implementation)
A project that contains the improved, optimized, and corrected implementation addressing the issues identified in Project A.
________________________________________
Each project must include its own code, environment requirements, setup scripts, test cases, and execution commands.
You must ensure that all files are generated, saved locally, and fully reproducible.
Both projects should handle optimizations, edge cases, and correctness verification while ensuring measurable improvements in stability and performance.
________________________________________
Title
Evaluation of GPT-5-Codex, GPT-5, Claude Sonnet 4.5, S100, and S40 on Bug-related – Regression Detection, Mitigation, and Optimization
________________________________________
Description
This experiment evaluates AI models' ability to detect, diagnose, and correct regression issues in software systems while optimizing overall performance and reliability.
Key Evaluation Criteria
• Correctness of both pre- and post-optimization implementations
• Efficiency and performance of regression mitigation solutions
• Handling of malformed inputs, hidden vulnerabilities, non-string inputs, and complex nested code
• Automated test coverage and reproducibility
• One-click setup and execution for both versions
• Quantitative comparison of stability, correctness, and performance before and after optimization
